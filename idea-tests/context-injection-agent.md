# Агент, который подставляет контекст другим агентам

## Идея
Отдельный агент, который подбирает и подставляет правильный контекст другим агентам, выполняющим текущие задачи.

## Вердикт
**Personal.** Для себя полезно, как бизнес слабо: место занято. Угол «доменный контекст для fintech/крипты» не списываю, но спрос не проверен.

## Рынок: идея распадается на два слоя, оба заняты

### Память агента (что помнит между сессиями)
- Mem0: Series A $24M, октябрь 2025 ([TechCrunch](https://techcrunch.com/2025/10/28/mem0-raises-24m-from-yc-peak-xv-and-basis-set-to-build-the-memory-layer-for-ai-apps/)).
- Zep, Letta, Cognee, Supermemory.
- Cloudflare Agent Memory, AWS AgentCore Memory.
- Провайдеры моделей встраивают память в свои продукты.

### Контекст компании для агентов (то, что описано в идее)
- Glean: MCP-шлюз, по его словам 78% клиентов подключили MCP и API ([Glean](https://www.glean.com/jp/blog/intelligent-secure-proactive-ai)).
- Atlan, Sourcegraph, Unblocked, Onyx.
- Источники в основном вендорские.

## Почему не бизнес
- Слой тонкий и копируется, своих данных или экспертизы нет.
- Сложная часть (права доступа, достоверность данных) на стороне крупных игроков.
- Конкуренция с провайдерами моделей.

## Почему для себя хорошо
Сырьё уже есть: Obsidian-vault, логи решений, репозиторий `ideas`, память. Практичная версия без нового фреймворка: markdown плюс семантический поиск, отданный агентам через MCP или файлы-инструкции ([DEV Community](https://dev.to/sebastian_chedal/agent-memory-038-knowledge-systems-compared-2026-guide-568p) описывает это как рабочий путь рядом с Mem0 и Zep).

## Возможный угол (гипотеза, не проверено)
Не универсальный слой, а доменный контекст для fintech и крипты: актуальные пакеты правил (MiCA, DAC8, travel rule), которые подставляются агентам, работающим с платёжными задачами. Тут есть экспертиза и данные, которые меняются.

## Проверка
- [ ] Неделю фиксировать случаи, когда агент ошибся из-за отсутствия контекста, и что именно ему не хватило.
- [ ] Для доменного угла: спросить 5 знакомых из платёжных и крипто-компаний, дают ли они агентам регуляторный контекст и как.

**Критерий:** если случаев нет, боли нет. Если есть и они повторяются, собрать минимальную версию на markdown и MCP.
