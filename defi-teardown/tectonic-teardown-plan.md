# План разбора Tectonic

Связано: [[shortlist]]

## Гипотеза
Падение TVL на 83% за 90 дней вызвано уходом пользователей, а не разовым событием. Проверяем по данным.

## Шаг 0. Проверка пригодности
- [ ] Команда активна в X за последний квартал.
- [ ] На Dune есть декодированные события контрактов Tectonic (Cronos).
- [ ] Просадка не объясняется только ценой токенов (сверить TVL в токенах и в USD).
- [ ] Нет хака, паузы рынков или объявленной миграции.

Если любой пункт провален, берём [[shortlist]] → Moonwell.

## Шаг 1. Данные
- [ ] Депозиты, займы, погашения, ликвидации по дням.
- [ ] Адреса кошельков с первым и последним действием.
- [ ] Эмиссия токена и реальные комиссии.

## Шаг 2. Метрики
- [ ] Когорты кошельков по месяцу первого депозита и retention.
- [ ] Доля TVL, державшаяся на стимулах (mercenary capital).
- [ ] Эмиссия против комиссий.
- [ ] Концентрация: доля топ-10 кошельков в TVL.
- [ ] Где в воронке отвал: депозит, займ, повторное использование.

## Шаг 3. Дашборд
- [ ] Публичный дашборд на Dune, ссылка в посте.

## Шаг 4. Публикация
Структура поста на LinkedIn:
1. Что наблюдаем (2–3 цифры).
2. Где теряются пользователи.
3. 2–3 конкретные рекомендации.
4. Ссылка на дашборд, отметка команды.

Правила тона: только цифры и выводы, без слов «мёртв», «скам», «неизбежный конец».

## Что считать результатом
Личные сообщения от людей, которые делают продукты, и просьбы разобрать их проект. Не лайки.
